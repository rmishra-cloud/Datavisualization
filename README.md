# Employee Performance Dashboard

## 📊 Overview
A comprehensive dashboard solution for tracking and analyzing daily employee performance metrics. This package includes both a web-based dashboard and Power BI template for management reporting.

## 📁 Files Included

### Core Dashboard Files
- `index.html` - Main dashboard webpage
- `dashboard.js` - Interactive JavaScript functionality
- `analysis_report.js` - Performance analysis and data processing
- `employee_data.csv` - Raw employee performance data

### Power BI Resources
- `PowerBI_Template_Instructions.md` - Step-by-step Power BI setup guide
- `employee_data.csv` - Data source for Power BI import

## 🚀 Quick Start

### Web Dashboard
1. Open `index.html` in any modern web browser
2. The dashboard will automatically load and display all visualizations
3. Share the URL with your manager for instant access

### Power BI Dashboard
1. Open Power BI Desktop
2. Follow instructions in `PowerBI_Template_Instructions.md`
3. Import `employee_data.csv` and create visualizations

## 🛠️ Technical Requirements

### Web Dashboard
- Modern web browser (Chrome, Firefox, Safari, Edge)
- No additional software required
- Works offline

### Power BI Dashboard
- Power BI Desktop (free download from Microsoft)
- Windows 10/11 or Power BI Service online
- CSV data import capability

## 📊 Dashboard Features

- **Interactive Charts:** Click and hover for detailed information
- **Responsive Design:** Works on desktop, tablet, and mobile
- **Real-time Metrics:** Key performance indicators prominently displayed
- **Detailed Analysis:** Comprehensive breakdown of all metrics
- **Professional Styling:** Clean, modern design suitable for management presentation

## 🔄 Data Updates

To update with new daily data:
1. Replace data in `employee_data.csv`
2. Update the `employeeData` array in `analysis_report.js`
3. Refresh the web dashboard or Power BI report
